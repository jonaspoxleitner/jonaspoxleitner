Photo Collector

Getting married or throwing a party? Photo Collector is a fully static, self-hosted app that lets your guests share their photos and videos with you. Guests scan a QR code, open a web page — no login, no app install — and upload directly to S3-compatible object storage. There is no backend and no database.

The QR code embeds write-only credentials, so guests can only upload, never read or delete. A companion CLI generates print-ready QR cards with a heart-shaped design for your tables.

photo-collector.vlkn.io

Cartographer

Cartographer merges GPX hiking routes into a single route graph, detecting intersections and retraced (shared) sections along the way. It is a Java 21 project built with Maven: a CLI renders the graph as an SVG map, and a Spring Boot server serves it as an interactive web map from pre-rendered vector tiles, alongside a GeoJSON API. Pathfinding across the merged routes is the end goal.
